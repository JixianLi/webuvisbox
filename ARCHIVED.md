# Archived: server-backed examples

This branch keeps the Wildfire and Uncertainty Tube example scenarios (`examples/Wildfire/`,
`examples/UncertaintyTube/`) as they were before their removal from `main`. Both fetch ensemble data from a data
server that is not part of this repository, and both use Chart.js for their charts.

`main` now ships only standalone examples that run entirely in the browser, and has no Chart.js dependency.
